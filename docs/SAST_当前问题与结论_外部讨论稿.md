## 1. 系统是什么

面向水泵水轮机振动信号故障诊断的**结构感知同步压缩变换（SAST）**，主干是一个可微的
时频增强网络。

### 1.1 数据与工况

- 采样 1000 Hz、单段 2000 点（2 s），频率分辨率 **0.5 Hz/bin**，F = 1000 bin。
- 5 个工况类：空转 / 低负荷 / 中负荷 / 高负荷 / 抽水。
- 训练 6575 / 验证 1160（val_split 0.15），类样本数 196 / 1786 / 587 / 3604 / 402。
- 机组参数：额定 333.3 rpm → f_rot = 5.5550 Hz；叶片数 Z_r = 9 → 1×BPF = 49.995 Hz
  （与 50 Hz 电网频率仅差 0.005 Hz，低于 0.5 Hz 分辨率，数值上不可区分）；
  2×BPF = 99.990 Hz。

### 1.2 主干流程（当前实现）

```
信号 x [B, 2000]
 → MSST-STFT (hl=1024, num=1)      → 幅值谱 T [B, 1000, T_f] + 每 bin 瞬时频率 ω̂ (int bin)
 → 3 个物理节点特征                 → V_obs(4维) → 5 条静态原型 soft matching → cond_ctx
 → 边特征(5维) + PPM + GAT(2层4头)  → w_i [B, 3, T_f]
 → σ_i = 0.20 + (1−w_i)·2.8   (∈[0.20, 3.0] bin, 软上限 3.0)
 → 软门控 g_m = clamp(w_i·M − (m−1), 0, 1), M = 2
 → 输出混合递推 S ← (1−g_m)S + g_m·Reassign(S)   （自定义 autograd Function）
 → tfr_enhanced
```

**三点与前版不同，需注意**：

1. `msst_num=1`（此前为 4）。4 次 lookup 迭代会把 BPF 带内 bin 的 IF 从 49.6–50.2 Hz
   一路拖到 45.8–48.3 Hz，偏离真实锁频线；`num=1` 即一阶 STFT IF，与基线 MSST 同口径。[实测]
2. `sigma_min` 0.5 → **0.20**。旧映射下硬带 `σ = 0.55–0.63 bin`，软门控 M=2 会把
   ±3σ 的高斯质量每轮摊开一次，脊线比 Raw MSST 粗、峰值被稀释，导致 41–50 Hz 段
   反而暗于 100 Hz；0.20 下 `σ(0.98)=0.256`、`σ(0.95)=0.34` bin。[实测]
3. `M` 3 → **2**（理由见 §6.5）。

### 1.3 物理节点（3 个）

| 节点 | 频带 (Hz) | 物理含义 | 类型 | C_prior | w_range |
|---|---|---|---|---|---|
| LOW_FREQ | [2, 18) | 水力涡带 / 压力脉动 | 软（HYDRAULIC） | 0.20 | [0.05, 0.35] |
| BPF | [40, 53) | 叶片通过族：41 Hz 流动峰 + 50 Hz 锁定线 | 硬（BLADE_PASS） | 0.90 | [0.80, 0.98] |
| 2×BPF | [90, 105) | 动静干涉，= 2·Z_r·f_rot | 硬（BLADE_HARMONIC） | 0.90 | [0.80, 0.98] |

- 2×BPF 带额外锚 `99.990 ± 1.5 Hz`；BPF 带**无锚**（带内混装非锁频的 41 Hz 流动峰与
  锁频的 50 Hz 线，能量加权 IF 落在两者之间，单个绝对锚失去意义）。
- `w_range` 是**软约束**（由损失施加），不是架构硬界；架构硬界见 §4.1。
- `bw_expected` = 4.5 / 3.0 / 4.5 Hz，`persist_expected` = 0.50 / 0.90 / 0.95。

## 2. 已确认的缺陷（均已修复）

### 2.1 48.0 Hz 硬边界造成"单峰劈裂伪峰" [实测]（4 节点期，已随节点合并消解）

原边界 `BPF_DRIFT[42,48]` / `BPF_LINE[48,53]` 且掩码两端皆闭，后果三重：bin 48.0 被双重计入；
空转的 `BPF_LINE` 带内 `E峰f = 48.000 Hz` 其实是 46.4 Hz 漂移峰右翼堆在窗口左缘形成的伪极值；
漂移翼瓣的泄漏是单向的（σ_drift 2.75 bin 时 18.0% 能量落到 48 Hz 以上），而硬边界对称地切。

修复为半开区间 + 共享内边互补升余弦过渡带（±0.5 Hz）构成单位分解 `Σ_n w_n(f) ≡ 1`，
7 处掩码副本收敛到单一真源 `region_weights()`。

修复效果：空转 BPF_LINE 的 `E峰f` 48.000 → **49.000 Hz**；空转 `presence_e` 0.317 → 0.135；
五类质心跨度 0.739 → 0.491 Hz；五类 `|锚−E峰f|` 最大 1.995 → 0.995 Hz（全部落入 ±1.5 容差）；
覆盖集 `Σ_n w_n(f)` 在 48.0 Hz 处由双计变为 `1.000000000`。[实测]

> 当前 3 节点架构下该边界不复存在；本节保留是因为"掩码必须半开 + 单位分解"这条教训
> 已固化进 `region_weights()`，未来换频段时仍适用。

### 2.2 `ridge_factor` 与"输出混合"递推架构不匹配 [实测 + 论证]

递推为 `S ← (1−part)·S + part·Reassign(S)`，`part = g_m·ridge_factor`。一个源 bin 每轮保留
`(1−part)` 倍能量在**原位**，M 轮后残余 `∏_m(1−g_m·ridge)`。

而 `ridge_factor` 是"源 bin 到脊线距离"的钟形衰减（floor 0.15）。MSST 的作用恰恰是把
**远离脊线的侧翼 bin** 的 ω̂ 指向脊线中心 —— **最该被搬走的 bin，正是 ridge 压得最低的**。

4 节点期实测（逐 bin `∏(1−part)`，真数据）：

| 节点 | ridge 均值 | 残留均值 | 残留 >0.1 的带内 bin 占比 |
|---|---|---|---|
| BPF_LINE | 0.774 | 0.165 | **50.9%** |
| BPF_DRIFT | 0.927 | 0.045 | 13.7% |
| 2xBPF | 0.965 | 0.027 | 2.3% |
| LOW_FREQ | 0.958 | 0.027 | 3.9% |

开关对照：BPF_LINE 带内 std 1.0310 → 0.6342（比值 0.615），与理论 `(1−0.15)³ = 0.614` 吻合到 0.2%。
20 epoch 全量对照（同 seed）：hard Rényi 7.853 → **7.721**、hard 带内 std 0.873 → **0.659**、
soft 带 Rényi 9.612 → **9.681**（软带更松 = 正确方向）、Val acc 两者均 1.000。[实测]

**两个轴同时变好，不是取舍。** `train_ridge` 默认已改为 `False`。

### 2.3 其余已修缺陷

- `n_sqz_per_bin` 被 `clamp(1,…)` 卡在 ≥1 → 推理**永远不可能 0 轮**，与设计文档写的
  "λ=0 → LOW_FREQ 不挤"直接矛盾。已被软门控 `g_m` 取代（`clamp` 版可真正到 0）。
- `bw_expected` 四个值全偏（12.0/6.0/1.5/2.0 → 实测 4.5/1.7/1.0/4.5）；3 节点合并后取
  4.5/3.0/4.5，并在 `sast_nodes.py` 注明取值理由。
- 工况原型与在线特征**归一化不一致**（旧原型 R 块之和 0.273–0.911，在线恒为 1.0），
  且 `E_lin = exp(log1p(x)) = 1+x` 而非 `expm1`。已用 `scripts/analysis/build_static_prototypes.py`
  按同一计算路径重算 5×4 原型。
- `FreqEncoder` 接收全 1000 bin（物理带只占 ≈88 bin，**91% 是带外**），带外特征的 1-NN
  工况分类精度 **0.800**（chance 0.200）[实测] —— 存在旁路。已加 `physics_band_mask`。

## 3. 关键负结果（都做了事前判据）

### 3.1 "自适应阶数"：无空间 [实测]（4 节点期）

`omegas[k]` **不是** Taylor 相位导数阶，而是同一个一阶 IF 估计的**固定点 lookup 迭代层**：
`ω_{k+1}[η,b] = ω_k[ω_k[η,b], b]`。层间差异确实存在（平均 |Δ| 0.74/0.58/0.35 Hz，
改变 bin 占比 67.7%/42.3%/18.2%），但按 Rényi / 集中度 / 锐度三项指标，
**四个分量的最优层一致落在最后一层**，即生产路径已在用的那层。事前判据
（存在 k\* 在窄带优于 k=num−1 且在宽带不劣化）**不成立**。

更根本的反驳：层间差异的效果方向与 σ / 轮数**完全同向且单调**（越深越集中），
选低层等价于"挤得更轻"，而 σ 已能连续可微地表达这一点。

**当前 `msst_num=1`：不是"不要多阶"，而是多阶在这份数据上会把锁频线拖偏**（§1.2）。

### 3.2 "自适应次数"（可微软门控）：可微但不承重 [实测]（4 节点期）

已把不可微的整数轮数 `round(w_i·M)` 替换为连续可微的 `g_m = clamp(w_i·M − (m−1), 0, 1)`，
训练与推理走同一条路径。验证通过：可微性（有限差分 vs autograd 相对误差 **5.7e-09**）、
训推一致（两 flag 之差 ÷ 同 flag 重跑之差 = **0.998**）、整数锚点回归（最大差 **0.000e+00**）。

**但消融显示它不是承重机制**（`--epochs 2 --max_samples 900`，同 seed）：

| 配置 | hard Rényi↓ | Val acc | T |
|---|---|---|---|
| base | 7.753 | 0.963 | 0.9683 |
| `--gate_detach 1`（只剩 σ 路径） | 7.754 | 0.963 | **0.9686** |
| `--sigma_detach 1`（只剩门控路径） | 8.200 | 0.985 | 0.9760 |

**断掉门控路径后结果几乎逐位相同** ⇒ 门控是 σ 路径的重参数化，不是独立监督信号。

### 3.3 (σ, R) 解耦无空间：单调 ⇒ 最优必在角点 [实测 + 论证]（4 节点期）

在 `(σ,R)` 平面扫网格 vs 沿 `w_i` 约束曲线 `σ=0.5+(1−w_i)·2.5, R=w_i·M` 扫：

| 节点 | 网格最优 (σ,R) | Rényi | 曲线最优 w_i | Rényi | 差距 |
|---|---|---|---|---|---|
| LOW_FREQ | (0.50, 3) | 8.4076 | 1.000 | 8.4076 | −0.00% |
| BPF_DRIFT | (0.50, 4) | 8.0390 | 1.000 | 8.0390 | 0.00% |
| BPF_LINE | (0.50, 3) | 7.1719 | 1.000 | 7.1719 | −0.00% |
| 2xBPF | (0.50, 3) | 8.2324 | 1.000 | 8.2324 | −0.00% |

**原理**：Rényi 在 R 上单调递减、在 σ 上单调递减（σ 越小越集中），故 (σ,R) 平面的最优
**必然是角点**；而 `w_i` 约束曲线恰是从 (σ大,R小) 单调走到 (σ小,R大) 的**同一条对角线**。
于是受约束最优 = 无约束最优。**只要目标单调，解耦按构造无收益。**

注：该实验的指标只测"带内集中度"，对软带是**错的目标**；但这不推翻结论，反而说清原理——
曲线覆盖了两个极端角点，无论某节点想要极端集中还是极端宽松，最优都在曲线端点上。

### 3.4 逐轮用中间 IF 层（复合式）反而更差 [实测]（4 节点期）

有人提出：既然 `omegas[-1]` 是 ω₀ 复合 4 次，那 M 轮都瞄准它就等于"目的地已到终点、再走无用"；
应在第 m 轮瞄准 `omegas[:, m−1]`。实测（σ=0.5, R=3，四节点）：**固定瞄准 `omegas[:,-1]` 全部更好**
（BPF_LINE Rényi 7.1519 vs 7.3186，std 0.326 vs 0.484）。

原因：`omegas[-1]` 是 lookup 迭代的**收敛不动点**，是对真实 IF 最好的估计；且重排**不幂等**
（`‖R(R(S))−R(S)‖/‖R(S)‖ ≈ 0.081~0.101`，每轮改变约 9%）。

### 3.5 多轮有效性：R=1→2 有收益，R≥2 饱和 [实测]（4 节点期）

| R | LOW_FREQ | BPF_DRIFT | BPF_LINE | 2xBPF |
|---|---|---|---|---|
| 1 | 8.4842 | 8.0078 | 7.1199 | 8.2429 |
| 2 | 8.3834 | 7.9955 | **7.0178** | 8.2217 |
| 3 | 8.3857 | 8.0031 | 7.0122 | 8.2222 |
| 4 | 8.3915 | 8.0092 | 7.0128 | 8.2241 |

⇒ **M 由 3 降到 2**（重排本体 192 ms → 128 ms）。当前 `n_sqz_max=2`。

### 3.6 一阶 vs 二阶 SST：判据决定结论 [实测]（4 节点期）

`sst2_stft` 提供真正的二阶（含 chirp 率修正 `q̂·τ̂`）IF，与一阶出自同一张 STFT。

- **按"带内集中度（Rényi↓）"判**：二阶在四个节点上**全输**。
- **按"带宽保真度"（增强谱展开度 ÷ 原始谱展开度，→1 = 未改变带宽）判**：二阶四个节点上都更保真。

| 节点 | 类型 | raw std | 一阶/raw | 二阶/raw |
|---|---|---|---|---|
| LOW_FREQ | 软 | 4.345 | 0.746 | **0.797** |
| BPF_DRIFT | 软 | 1.890 | **0.640** | **0.924** |
| BPF_LINE | 硬 | 1.212 | 0.740 | 0.873 |
| 2xBPF | 硬 | 3.755 | 0.453 | 0.903 |

**这个矛盾本身就是核心问题之一**：两个判据给出相反结论，而"谁对"取决于**目标带宽是什么**。
后续结论见 §6.4：两个判据分别适用于硬带与软带。

## 4. `w_i` 到底被什么约束？（本轮新增，核心讨论点）

这一节回答一个此前没有被系统梳理过的问题：

> **损失下降之后，模型认为"什么样的 `w_i` 才是好的"？**

答案是：**物理意义主要来自人工框，不来自优化**。优化器实际做的是在几堵墙之间把 `w_i`
推到端点。

### 4.1 约束清单

#### (a) 架构层（最硬，不可越过）

```python
# models/sast.py:597-603
w_logits = 4.0 * torch.tanh((logits_mlp + w_ref_logit) / 4.0)   # ∈ (−4, 4)
w_i = torch.sigmoid(w_logits)                                    # ∈ (0.018, 0.982)
# 其中 w_ref_logit = logit(C_prior)，以偏置形式加入 ⇒ 初值 w_i ≈ C_prior
```

设计目的是防 sigmoid 饱和（旧实现硬带 logit 冲到 +54/+108，`w_range`/`balance` 在数值上死亡）。
副作用是：**每个节点的起点和上下限都由 `C_prior` 与常数 4 决定**。

#### (b) 参数空间正则（不看数据）

| 项 | λ | 形式 | 推向 |
|---|---|---|---|
| `L_range` | 1.0 | 逐帧平方 hinge，出界 `[w_low_eff, w_high]` 才罚 | 区间内 |
| `L_balance` | 0.5 | 节点**时间均值**落在区间内 | 区间内 |
| `L_w_center` | 0.05 | `(w_i − c_eff)²`，`c = C_prior`，presence→0 时下沉 0.05 | 回先验中心 |
| `L_var` | 0.5 | `relu(0.05 − Var_n(w̄))` | 节点间拉开 |
| `L_consistency` | 1.0 | `Var_t + 20·(Δ1ms)² + 2·(Δ250ms)²` | 时间恒定 |

#### (c) 数据驱动（经增强谱反传）

| 项 | λ | 作用 | 推向 |
|---|---|---|---|
| `L_entropy`（RE_2D） | 0.1 | 硬带**无条件**最小化 2D Rényi 熵（软带 skip） | `w` 上升 |
| `L_soft_ent` | 0.5 | 软带：只允许熵降 ≤ 0.55 nats | `w` 下降 |
| `L_lowfreq` | 0.05 | 软带 Rényi × tonality | 弱上升（涡带 tonality 低，基本不触发） |
| `L_supcon` | 0.2 | encoder 看增强谱，推"5 类更可分" | 让类间距变大 |

#### (d) 不进入反向

`L_physics` / `L_anchor` / `L_ratio` —— **频率锚与谐波比值完全不约束 `w_i`**。

### 4.2 两条梯度通路都通到 `w_i`

```
w_i ──► σ_i = 0.20 + (1−w_i)·2.8 ──► Reassigner 内核（custom backward 回传 grad_sigma）
    └─► g_m = clamp(2w_i − (m−1), 0, 1) ──► 输出混合（∂S/∂g = R − S）
```

两条通路都非空：σ 路径由 `ReassignerFunction.backward` 解析给出 `grad_sigma`；
门控路径由输出混合的 `R − S` 给出。

**关键限制**：ω̂（落点 IF）是 **int64、不可微、不参与学习**。所以 `w_i` 只能决定
"要不要沿这条 IF 搬能量"，**不能修正 IF 本身**。

真正塑造 `w_i` 的只剩架构界 + 两项数据驱动项。

### 4.4 所以损失"认为"的"好 `w_i`"是什么

1. **硬带：越高越好。** `RE_2D` 无条件最小化熵，没有任何上界制动；唯一的刹车是
   `w_range_high = 0.98` 与 `M = 2`。
2. **软带：越低越好。** `L_soft_ent` 主导，唯一的刹车是 `w_range_low = 0.05`。
3. **时间上恒定**（`L_consistency`，实测已完全满足）。
4. **节点间差异大**（`L_var` 目标 0.05；实测节点间方差约 0.17，恒为 0，已失去作用）。

本质是"**两堵墙 + 一个单调目标**"，最优解必然贴墙 —— 这与 §3.3 的角点结论同源。

### 4.5 物理意义的四层评估

**① 真有物理的：软/硬二分 + 逐节点区间。**
区间来自 §2/§6 的数据判据（带内有效带宽 B_eff、谱纯度 PMR、相位漂移 σ_f），
与同步压缩理论的可压缩条件同源。这是"把物理先验编码进架构"，成立。

**② 要打折的：文献里"σ 是数据带宽的可微函数"。**
形式上对（σ 关于 `w_i` 连续单调），但 `w_i` 被两堵墙夹住，实测就是两个端点。
"σ 按三组均值严格单调"是**构造保证的**（σ 单调依赖于 w，而 w 的区间排序是人工给的），
不是模型从 `B_eff` 里发现的。

**③ 三个缺失的制动：**

- **硬带没有"过度挤压"上界。** §2.1 之外的数据结论明确：BPF 在 4 个加载工况不应被硬挤
  （B_eff 8.6–9.6 Hz、PMR 6.0–8.0 dB），但损失完全不知道这件事 —— 它只会把 `w` 顶到 0.98。
- **presence 门控存在但没生效。** 空转 2×BPF 分量缺席（`presence = 0.074` vs 加载工况
  0.238–0.256），`w_low_eff` 应松到 0.05，实测仍是 0.973。
- **"IF Trust" 名不副实。** 没有任何一项损失检验 IF 是否准确；唯一的间接联系是
  "IF 准 → 挤压后熵更低"。所以 `w_i` 的真实语义是"沿这条固定 IF 搬能量值不值得"，
  而不是"这条 IF 可不可信"。

**④ 没有物理内容的：**

- `L_var`：纯反退化，已恒 0；
- `L_supcon` 对 `w_i` 的作用是"让 5 类更可分"——这是**判别性**，不是物理。
  λ=0.2 且 encoder 输入已 mask 到物理带，风险被压住，但通路是活的。

### 4.6 一句话总结

> `w_i` 是一个**被人工物理先验框住的插值量**：物理意义来自**框**（软硬二分、逐节点区间、
> 时间平稳），不来自**优化**。优化器的工作只是在这几堵墙之间把 `w` 推到两端。

要让物理意义真的由数据决定，缺两样东西：**硬带的过挤压上界**，以及**一个真正检验
IF 质量的监督信号**。

### 5.1 关于 `w_i` 的物理意义（新增，优先级最高）

1. **硬带该不该有"过度挤压"的刹车？** 现在软带有相对熵降 hinge（`L_soft_ent`），硬带没有。

2. **"IF Trust" 是否应重构？** 要不要引入一个真正度量 IF 质量的量（例如相邻帧 IF 的

   代价：这股监督可能不可微，或与 σ 的作用混淆。
3. **`w_i` 贴墙饱和（0.980）是否说明区间约束太窄、或数据驱动项太强？**

4. **`L_supcon` 经 σ / 门控通路给 `w_i` 判别性梯度，是否应该 `detach`？**

5. **presence 门控未生效是实现问题还是概念问题？**

   是否需要一个显式的缺席惩罚（而不仅是放宽区间）？
   **→ 已结（2026-11-01）：是实现问题，已实现缺席门控。见下方增补。**

#### 5.1 增补（2026-11-01，已审结）：算子级 IF 质量 `Q_IF` 的两轮探针

第 2 问的重构方案之一是：用 SST 相位驻点理论构造一个逐节点逐帧的 IF 质量分，
再驱动 `w_i`。定义（`scripts/analysis/probe_q_if.py`，只读，验证集 5 类 × 10 条）：

```
q_vert(f,t) = exp(−(ω̂(f+1,t) − ω̂(f−1,t))² / (2·1.0²))      # 频域主瓣共识
q_temp(f,t) = exp(−(ω̂(f,t+20) − ω̂(f,t−20))² / (2·1.5²))    # 时域平稳 (Δt=20 ms)
Q_IF(n,t)   = clamp(presence_n(t)/0.20, 0, 1)
              · Σ_f |S_raw|²·q_vert·q_temp / Σ_f |S_raw|²
```

**第一轮（Q_IF 原式）：判据 1/3 通过。**

| 判据 | 要求 | 实测 | 结果 |
|---|---|---|---|
| (1) LOW_FREQ 最低 | < 0.30 | 0.345 / 0.414 / 0.432 / 0.374 / 0.366 | FAIL |
| (2) 缺席 vs 存在 | 空转 < 0.25 且加载 > 0.75 | 0.226 vs 0.789 / 0.873 / 0.897 | PASS |
| (3) BPF 随负荷连续梯度 | 0.50 ~ 0.85 | 0.608 / 0.447 / 0.411 / 0.354 / 0.320 | FAIL |

**失败根因一：地板不是 0，是 ≈0.45。** 同口径合成信号标定：纯 50 Hz 单音在 BPF 带
`Q_raw = 0.922`；**纯白噪声 0.44–0.49**。白噪声的 `ω̂` 在邻 bin 随机游走，
`E[(Δ_{2bin}ω̂)²] ≈ 1.4 bin²` ⇒ `q_vert` 期望 `exp(−0.7) ≈ 0.5`。判据 (1) 要求的
0.30 在数学上不可达 —— LOW_FREQ 已经是"噪声级"，但绝对阈值落在地板以下。

**失败根因二：BPF 的方向是反的。** 空转 0.61 → 高负荷 0.35，全部来自 `q_vert`
（空转 0.683 vs 加载 0.51–0.61），`q_temp` 几乎不动（0.92–0.95）。机理：[40, 53)
内 41 Hz 流动峰与 50 Hz 锁频线共存，两簇脊线交界处 `ω̂` 逐 bin 跳变。
**该指标度量的是"带内谱纯度"，不是"锁频线的 IF 质量"。** 另：空转 BPF 本身双峰，
10 条里 4 条落 0.34–0.46、6 条落 0.65–0.87，工况内部就不均匀。

**第二轮（`probe_q_if_norm.py`）：扣地板归一化 + 只取脊线核心 bin。**
`Q_norm = clamp((Q_raw − q_noise)/(1 − q_noise), 0, 1)`，`q_noise` 按"口径 × 节点"
逐个标定（full 0.455/0.465/0.447；τ=0.25 0.494/0.503/0.488；top-3 0.548/0.578/0.542）；
核心 bin 取每帧带内 `E ≥ τ·max E`（τ=0.25）或 top-3。

| 口径 | (1) LOW_FREQ < 0.30 | (2) 空转 2×BPF < 0.25 且加载 > 0.75 | (3) BPF ∈ [0.50, 0.85] | 四锚点排序 |
|---|---|---|---|---|
| full | **PASS**（max 0.209） | FAIL（0.107 vs 0.634/0.773/0.817） | FAIL（0.399→0.141） | 自洽 |
| τ=0.25 | **PASS**（max 0.283） | FAIL（0.147 vs 0.722/0.812/0.843） | FAIL（0.458→0.179） | 自洽 |
| top-3 | FAIL（max 0.390） | FAIL（0.252 vs 0.789/0.838/0.861） | FAIL（0.518→0.285） | 自洽 |

三点结论：

1. **归一化救回判据 (1)**：LOW_FREQ 从 0.35–0.43 降到 0.11–0.28。它本来就处在噪声
   地板上，原阈值定错了，不是指标坏了。
2. **判据 (3) 修不回来**：三种口径下 BPF 都保持"空转最高、随负荷单调下降"。
   核心 bin 筛选只是把倒挂幅度收窄（0.399→0.141 变成 0.518→0.285），方向不变。
   按事前规则 ⇒ **放弃把 `Q_IF` 作为损失项**。
3. **四锚点排序在三种口径下全部自洽**：空转 2×BPF < LOW_FREQ < BPF < 加载 2×BPF
   （full：0.11 < 0.16 < 0.22 < 0.74）。它作为**相对比较的评估量**是可靠的。

**处置**：`Q_IF` 收入 `sast_inference.evaluate_tf_quality`（新增逐节点 `q_if`，
full 口径 + 匹配节点地板，不含 presence 门控）。⚠ 它算在 **`tfr_raw`** 上，
**与模型参数无关** —— 因此它是"该频带/工况固有的脊线质量"的一个常数参考，
不会随 epoch 变化。它与 Rényi 配对才有意义：`Rényi` 测"增强谱有多集中"，
`Q_IF` 测"输入里这条脊线到底存不存在、平不平稳"，两者可以背离（增强谱能把
底噪压成尖峰而 `Q_IF` 不动）。当前 checkpoint（`3node_e15`，15 条混合工况样本）
实测 0.151 / 0.212 / 0.619。

**留给外部意见的问题**：既然 `Q_IF` 在 BPF 上必然倒挂，那么"该不该挤"是否根本
不该由带级标量决定，而应由**逐 bin** 的脊线归属（同一带内 41 Hz 流动峰 vs 50 Hz
锁频线）决定？这等价于把节点粒度做到 bin 级，与 §5.2 的架构问题相连。

#### 5.1 增补（2026-11-01，已结）：第 5 问 —— 缺席门控（absence gate）

**结论：是实现问题，不是概念问题。** 第 5 问的猜测"允许下界松弛 ≠ 模型会选择松弛"
成立，但它漏掉了另一半：**上界从未被放松**。0.973 本来就在 `[w_low_eff, 0.98]`
区间内，是**合法解**；`RE_2D` 又无条件向上推，所以模型没有任何理由离开 0.98。
"放宽下界"这一整类做法在原理上都无法把 `w` 拉下来。

**修复（三个改动，同一份缺席度 a 驱动）**

```
a_n(t)        = clamp((p_hi − e_n(t)) / (p_hi − p_lo), 0, 1)      # 逐节点门限
RE_2D         : h 按 (1 − a) 加权 —— a=1 时该项对样本的梯度严格为 0
w_range       : w_high_eff = 0.20 + (1 − a)·(w_range_high − 0.20)  # 逐帧
L_balance     : w_max_eff  = 0.20 + (1 − ā)·(w_range_high − 0.20)  # 时间均值
```
a=0（分量存在）时三项**逐位等于**修改前（单元核对 Δ<1e-9），所以不会误伤加载工况。

**为什么必须是逐节点门限，而不是全局阈值 / presence 线性插值** [实测]

presence 的尺度是**压缩且节点相关**的（50 样本，逐帧）：
LOW_FREQ 0.211/0.143/0.198/0.162/0.147、**BPF 0.229/0.183/0.126/0.145/0.136**、
2xBPF **0.092**/0.285/0.317/0.342/0.314（类 0–4）。
BPF 的 presence 与负荷**反相**（空转最高）：空转带内只剩一条平坦的 48 Hz 漂移峰，
集中度反而高；加载后 41 Hz 流动峰把能量摊开。若对它门控，被压上界的是**加载**工况。
中途实现过的"presence 线性插值上界"正是踩了这个坑：e=0.30 时
`w_high_eff = 0.20 + 0.30×0.78 = 0.434`，会直接打掉加载工况的 0.98。故改为
**二值化门限 + 只对 2xBPF 启用**（BPF / LOW_FREQ 的 `p_absent_hi = 0`，a≡0）。

**门限标定**（`scripts/analysis/probe_absence_frames.py`，50 样本 × 2000 帧）：

| (lo, hi) | 空转 2xBPF `a` 均值 | 加载类 1–4 误判帧占比 |
|---|---|---|
| (0.10, 0.20) | 0.88 | 9% / 6% / 5% / 7% |
| **(0.13, 0.17)** | **0.91** | **5% / 2% / 0% / 2%** |
| (0.14, 0.19) | 0.95 | 8% / 5% / 4% / 6% |

取 (0.13, 0.17)：空转 2xBPF 逐帧 presence 均值 0.092（p90 0.144），加载 0.285–0.342
（p10 0.199），两簇在帧级也分得开，不需要把门限压到两簇边上。

2. **B5a/B5b 从"无差别"变成"明显掉"。** 无门控时掩掉整张图，软带 cos 仍

## 6. 历史结论（4 节点期实测，已归档）

以下结论在 4 节点架构下测得，节点名保持原样。§3 已复述与节点数无关的部分，
这里保留与"目标带宽"直接相关的两条。

### 6.1 `bw_target`：对 LOW_FREQ 成立，对漂移型分量**原理上不成立** [实测]

定义：`E_raw` 加权、第 0 层未折叠瞬时频率的带内加权标准差。

**原理正确** [论证]：理想单频 `V(f,t) = e^{i2πf₀t}·ĝ(f−f₀)`，相位导数 `2πf₀` **与 f 无关**，
窗泄漏只污染幅值、不污染相位导数 → 纯音 `bw_target ≡ 0`。
合成验证：含纯音的带给出 **0.052–0.088 Hz**（≈ Sheppard 量化底 `0.5/√12 = 0.144 Hz`）；
`E² = |S|⁴` 加权后更低。峰/底噪幅值比 10:1 时，线性权重下 28 个底噪 bin 占 21.9%，
平方后仅 0.28%。[实测]

**但真实数据上软/硬顺序是错的** [实测]（`E²` + 锁定带本底校准，本底 0.466 Hz）：

| 节点 | 类型 | E² 校准后 | vs 本底 |
|---|---|---|---|
| LOW_FREQ | 软 | **2.789** | 6.0× ✓ |
| **BPF_DRIFT** | **软** | **0.686** | **1.47×** ✗ |
| BPF_LINE | 硬 | 0.584 | 1.25× ✗ |
| 2xBPF | 硬 | 0.650 | 1.39× ✗ |

**失败原因是概念性的**：`bw_target` 度量**单帧内的瞬时弥散**，而两类"软"是**两种不同的软**：

- **LOW_FREQ = 瞬时宽带湍流** —— 帧内不同 bin 的局部振荡频率确实不同，逐帧 std 抓得到；
- **漂移型（BPF_DRIFT）= 中心频率随帧间游走** —— **任何单帧内它都是窄的**，
  其"带宽"来自 f₀(t) 在帧间的移动；逐帧 std 只看得到帧内的窄，于是塌到接近底。

要抓漂移型需要**跨时间的** f₀ 游走幅度（帧间统计），那是另一个量、需单独定义。
**把两者当成同一类"软分量"，是这套方案的漏洞。**

> 3 节点合并后，漂移型分量已并入 BPF 硬带，这条**原理性缺口在当前架构下不再产生
> 错误判定**；但若将来重新拆分节点，它会立刻回来。

**处置**：`bw_target` 暂不进入损失。

### 6.2 §4.2 已定：选 (A)，理由比原先更强

保留 GAT 输出 `w_i → σ_i`，`bw_target`（校准后）作为**损失目标** `L_bw`、由 `presence` 门控。

**物理理由** [论证]：单帧局部测量是**高方差且盲目**的 —— 空转工况下 2×BPF 真实分量缺席、
带内全是底噪，单帧算出的初阶相位标准差测的是纯噪声的随机相位跳变，会飙到 3–5 Hz。
若用方案 (B) 直接拿它当 `σ_i(t)`，**每一帧的核宽都会随局部噪声剧烈抖动**（违背 `L_consistency`）。
GAT 具备单帧单带测量没有的能力：跨节点图推理（HARMONIC / CONDITION / DRIFT /
ENERGY_COMPETITION 四类边）+ 全局工况上下文 `V_obs` 先验。

即 **GAT 扮演的是"跨频带结构去噪 + 贝叶斯后验平滑"，不是对单帧带噪统计量的复制**。

### 6.3 旁路：已修，但不改变"门控不承重"的结论

已实施 `physics_band_mask(freqs)`（3 个物理带并集，≈88/1000 bin）乘在全部 `freq_encoder`
调用点，`freq_encoder_masked` 默认 True。早期证据：掩码一上，`L_supcon` 立即从 0.00–0.02
跳到 3.20 —— 编码器不再能平凡分开工况。[实测]

**但这不改变 §3.2**：`g_m(w_i)` 与 `σ_i(w_i)` 都是同一标量 `w_i` 的确定性函数；屏蔽带外
只是让梯度**重新流回 `w_i`**，不改变"两路共线、σ 主导"这个结构事实。
（"梯度是否到达 `w_i`"与"`g_m` 是否是独立自由度"是两个不同的问题。）

### 6.4 `bw_target` 判据之争：**两者都对，但各管一半**

- **硬带（2×BPF 为代表）**：真实本征带宽 ≈ 0（2×BPF 逐样本 std = **0.000 Hz**），
  raw std 3.755 几乎全是窗泄漏 + 底噪 → **集中度判据对，越小越好**。
  故一阶 MSST 胜出，二阶保留更多"原始宽度"是**重排散焦**，不是保真。**此结论接受。**
- **软带（LOW_FREQ）**：raw std 4.345 Hz **大部分是真实的**（16 Hz 宽的宽带涡带）。
  按方差可加性扣掉窗泄漏（Hann-512 主瓣约 3.65 Hz）后真实展宽约
  `sqrt(4.345² − 1.5²) ≈ 4.1 Hz`，而一阶把它压到 **3.241**（0.746×）——**压过头了**。
  故软带上"保真度"判据并非假象。

**两个判据分别适用于硬带与软带，而不是一个对、一个错。**

### 6.5 `M` 的取值

`M: 3 → 2`。§3.5 显示 R=1→2 有实质收益（BPF_LINE Rényi 7.1199 → 7.0178），
R=2→3→4 完全进入平台（7.0178 / 7.0122 / 7.0128）。取 M=2 既在拐点上，
又把单步重排 192 ms 降到 128 ms（省 33%）。

## 8. 一句话版本

> SAST 的 `w_i` 不是从数据里"学出来"的连续物理量，而是**被人工区间框住的插值量**：
> 硬带被熵目标顶到上限 0.98，软带被相对熵 hinge 压到下限附近，时间上恒定。
> 它的物理意义来自框（软硬二分、逐节点区间），不来自优化。
> 当前最需要外部意见的是：**要不要给硬带加过挤压刹车、要不要让 `w_i` 真的反映 IF 质量。**
