# SAST 当前状态：已确认缺陷、实测结论与待决问题

> 本文是给外部讨论用的自包含技术简报。所有数字均为本仓库实测，标注了 [实测] / [论证]，
> 以便区分证据与推理。代码位置以 `文件:行` 给出。

## 1. 系统是什么

面向水泵水轮机振动信号故障诊断的**结构感知同步压缩变换（SAST）**，主干是可微的时频增强网络。

**数据**：1000 Hz 采样、2000 点（2 s），5 个工况类（空转/低负荷/中负荷/高负荷/抽水）。
训练集 5475 / 验证集 1160（val_split 0.15）。

**主干流程**：

```
信号 x [B,2000]
 → MSST(num=4, 即 4 次 lookup 迭代)  → 复数 STFT + IF 轨迹 omegas[B,4,F,T]   (F=1000, df=0.5Hz)
 → 4 个物理节点特征                 → V_obs(6维) → 静态原型 soft matching → cond_ctx
 → 边特征 + PPM + GAT               → w_i [B, 4, T]
 → σ_i = 0.5 + (1-w_i)·2.5  (∈[0.5,3.0] bin)
 → 门控 g_m = clamp(w_i·M-(m-1), 0, 1), M=3
 → 高斯基重排 (自定义 autograd Function)  → tfr_enhanced
```

**4 个物理节点**（由实测谱分析确定，非人为划分）：

| 节点 | 频带 (Hz) | 物理含义 | 类型 |
|---|---|---|---|
| LOW_FREQ | [2, 18) | 水力涡带 / 压力脉动 | 软（应保留展宽） |
| BPF_DRIFT | [42, 48.5) | 工况漂移宽峰（频率由流动不稳定性决定） | 软 |
| BPF_LINE | [48.5, 53) | 转速锁定线 1×BPF = Z_r·f_rot = 49.995 Hz | 硬（应锐化） |
| 2xBPF | [90, 105) | 2×BPF = 99.990 Hz | 硬 |

关键机组参数：额定 333.3 rpm → f_rot = 5.5550 Hz，转轮叶片数 Z_r = 9 → 1×BPF = 49.995 Hz
（与 50 Hz 电网频率仅差 0.005 Hz，低于 0.5 Hz 分辨率，数值上不可区分）。

**损失**：`RE_2D`（Rényi 2D 熵，**仅对硬带**最小化）、`L_supcon`(λ=0.2)、
`L_balance`/`L_var`/`L_consistency`/`L_lowfreq`/`L_range`。
**没有分类头**；验证用 KNN 到 `z_freq` 类中心。

## 2. 已确认的缺陷（均有实测证据）

### 2.1 48.0 Hz 硬边界造成“单峰劈裂伪峰” [实测]

原边界 `BPF_DRIFT[42,48]` / `BPF_LINE[48,53]`，且掩码两端皆闭，后果三重：

1. bin 48.0 被两个区域**双重计入**；
2. 空转的 `BPF_LINE` 带内 `E峰f = 48.000 Hz` —— 这不是 50 Hz 线，而是 46.4 Hz 漂移峰的
   右翼堆在**窗口左缘**形成的伪极值；其后果是空转 `presence_e(BPF_LINE) = 0.317`，
   **全类最高**，与物理直觉完全相反（低负荷最低 0.082）；
3. 漂移翼瓣的泄漏是**单向**的（σ_drift ∈ [1.75,2.75] bin，单个 46.9 Hz 源在 σ=2.75 时
   18.0% 能量落在 48 Hz 以上；σ_line ∈ [0.625,1.375] bin 几乎不向左漏），但硬边界对称地切。

**修复**：边界改为 `[42,48.5)` / `[48.5,53)`（半开），共享内边两侧用互补升余弦过渡带
（±0.5 Hz）构成**单位分解** `Σ_n w_n(f) ≡ 1`，外缘保持硬 0/1。
7 处独立的掩码副本收敛到单一真源 `region_weights()`。

**修复效果** [实测]：

| 检查项 | 改前 | 改后 |
|---|---|---|
| 空转 BPF_LINE 的 E峰f | 48.000 Hz | **49.000 Hz** |
| 空转 presence_e(BPF_LINE) | 0.317 | 0.135 |
| BPF_LINE 五类质心跨度 | 0.739 Hz | 0.491 Hz |
| 五类 \|锚−E峰f\| | 最大 1.995 Hz | 最大 0.995 Hz（全部落入 ±1.5 容差） |
| BPF_DRIFT 五类 E峰f | 46.417/47.667/47.583/46.625/47.708 | **逐位不变**（真实峰未被削） |
| 覆盖集 Σ_n w_n(f) | 48.0 Hz 处双计 | `1.000000000` |

### 2.2 `ridge_factor` 与“输出混合”递推架构不匹配 [实测 + 论证]

递推为 `S ← (1-part)·S + part·Reassign(S)`，`part = g_m·ridge_factor`。
一个源 bin 每轮保留 `(1-part)` 倍自身能量在**原位**，M 轮后残余 `∏_m(1-g_m·ridge)`。

而 `ridge_factor` 是“源 bin 到脊线距离”的钟形衰减（floor 0.15）。MSST 的作用恰恰是把
**远离脊线的侧翼 bin** 的 ω̂ 指向脊线中心 —— **最该被搬走的 bin，正是 ridge 压得最低的**。

**实测（逐 bin 的 `∏(1-part)`，真数据）**：

| 节点 | ridge 均值 | ridge 最小 | 残留均值 | 残留 >0.1 的带内 bin 占比 |
|---|---|---|---|---|
| **BPF_LINE** | 0.774 | 0.150（floor） | 0.165 | **50.9%** |
| 2xBPF | 0.965 | 0.856 | 0.027 | 2.3% |
| BPF_DRIFT | 0.927 | 0.216 | 0.045 | 13.7% |
| LOW_FREQ | 0.958 | 0.590 | 0.027 | 3.9% |

**开/关 ridge 的直接对照** [实测]：BPF_LINE 带内 std **1.0310 → 0.6342**（比值 **0.615**），
与理论 `(1−0.15)³ = 0.614` 吻合到 0.2%。

**20 epoch 全量对照** [实测]（同 seed）：

| 指标 | ridge=1 | ridge=0 |
|---|---|---|
| hard 带 Rényi↓ | 7.853 | **7.721** |
| hard 带内 std↓ | 0.873 | **0.659** |
| soft 带 Rényi | 9.612 | **9.681**（软带更松 = 正确方向） |
| Val acc | 1.000 | 1.000 |
| 总损失 T | 0.854 | **0.835** |

**两个轴同时变好，不是取舍。** 已把 `train_ridge` 默认改为 `False`。

### 2.3 其余已修缺陷

- `n_sqz_per_bin` 被 `clamp(1,…)` 卡在 ≥1 → 推理**永远不可能 0 轮**，与设计文档写的
  “λ=0 → LOW_FREQ 不挤”直接矛盾 [实测]。
- `bw_expected` 四个值全偏：12.0/6.0/1.5/2.0 → 实测应为 4.5/1.7/1.0/4.5 [实测]。
- 工况原型与在线特征**归一化不一致**（旧原型前三列之和 0.273–0.911，在线恒为 1.0），
  且 `E_lin = exp(log1p(x)) = 1+x` 而非 `expm1` [实测]。
- `FreqEncoder` 接收全 1000 bin（4 个物理带只占 84 bin，**92% 是带外**），
  带外特征的 1-NN 工况分类精度 **0.800**（chance 0.200）[实测] —— 存在旁路。

## 3. 关键负结果（都做了事前判据）

### 3.1 “自适应阶数”：无空间 [实测]

`omegas[k]` **不是** Taylor 相位导数阶，而是同一个一阶 IF 估计的**固定点 lookup 迭代层**：
`ω_{k+1}[η,b] = ω_k[ω_k[η,b], b]`。`num=4` → 4 层。

层间差异确实存在（平均 |Δ| 0.74/0.58/0.35 Hz，改变 bin 占比 67.7%/42.3%/18.2%），
但按 Rényi / 集中度 / 锐度三项指标，**四个分量的最优层一致落在 k=3**，即生产路径已在用的那层。
事前判据（存在 k\* 在窄带优于 k=num−1 且在宽带不劣化）**不成立**。

更根本的反驳：层间差异的效果方向与 σ / 轮数**完全同向且单调**（越深越集中），
选低层等价于“挤得更轻”，而 σ 已能连续可微地表达这一点。

### 3.2 “自适应次数”（可微软门控）：可微但不承重 [实测]

已把不可微的整数轮数 `round(w_i·M)` 替换为连续可微的
`g_m = clamp(w_i·M − (m−1), 0, 1)`，训练与推理走**同一条**路径。

验证通过：可微性（有限差分 vs autograd 相对误差 **5.7e-09**）、训推一致
（两 flag 之差 ÷ 同 flag 重跑之差 = **0.998**）、整数锚点回归（与“硬 k 轮”最大差 **0.000e+00**）。

**但消融显示它不是承重机制**（`--epochs 2 --max_samples 900`，同 seed）：

| 配置 | hard Rényi↓ | Val acc | T |
|---|---|---|---|
| base | 7.753 | 0.963 | 0.9683 |
| `--gate_detach 1`（只剩 σ 路径） | 7.754 | 0.963 | **0.9686** |
| `--sigma_detach 1`（只剩门控路径） | 8.200 | 0.985 | 0.9760 |

**断掉门控路径后结果几乎逐位相同** ⇒ 门控是 σ 路径的重参数化，不是独立监督信号。
而 σ 是 v4 就有的东西。

### 3.3 (σ, R) 解耦无空间：单调 ⇒ 最优必在角点 [实测 + 论证]

在 `(σ,R)` 平面扫网格 vs 沿 w_i 约束曲线 `σ=0.5+(1−w_i)·2.5, R=w_i·M` 扫，四个节点：

| 节点 | 网格最优 (σ,R) | Rényi | 曲线最优 w_i | Rényi | 差距 |
|---|---|---|---|---|---|
| LOW_FREQ | (0.50, 3) | 8.4076 | 1.000 | 8.4076 | −0.00% |
| BPF_DRIFT | (0.50, 4) | 8.0390 | 1.000 | 8.0390 | 0.00% |
| BPF_LINE | (0.50, 3) | 7.1719 | 1.000 | 7.1719 | −0.00% |
| 2xBPF | (0.50, 3) | 8.2324 | 1.000 | 8.2324 | −0.00% |

**原理**：Rényi 在 R 上单调递减、在 σ 上单调递减（σ 越小越集中），故 (σ,R) 平面的最优
**必然是角点**；而 w_i 约束曲线恰是从 (σ大,R小) 单调走到 (σ小,R大) 的**同一条对角线**。
于是受约束最优 = 无约束最优。**只要目标单调，解耦按构造无收益。**

注：该实验的指标只测“带内集中度”，对软带是**错的目标**（软带要保留展宽）；但这不推翻结论，
反而说清原理——曲线覆盖了两个极端角点，无论某节点想要极端集中还是极端宽松，最优都在曲线端点上。

### 3.4 逐轮用中间 IF 层（复合式）反而更差 [实测]

有人提出：既然 `omegas[-1]` 是 ω₀ 复合 4 次，那 M 轮都瞄准它就等于“目的地已到终点、
再走无用”；应在第 m 轮瞄准 `omegas[:, m−1]`，让重排本身完成复合。

实测（σ=0.5, R=3，四个节点）：**固定瞄准 `omegas[:,-1]` 全部更好**
（BPF_LINE Rényi 7.1519 vs 7.3186，std 0.326 vs 0.484）。

原因：`omegas[-1]` 是 lookup 迭代的**收敛不动点**，是对真实 IF 最好的估计；逐轮爬中间层
等于用更差的落点估计。且“原地踏步”的前提本身不成立——实测重排**不幂等**
（`‖R(R(S))−R(S)‖/‖R(S)‖ ≈ 0.081~0.101`，即每轮改变约 9%）。

### 3.5 多轮有效性：R=1→2 有收益，R≥2 饱和 [实测]

同目标、同 σ、只改轮数：

| R | LOW_FREQ | BPF_DRIFT | BPF_LINE | 2xBPF |
|---|---|---|---|---|
| 1 | 8.4842 | 8.0078 | 7.1199 | 8.2429 |
| 2 | 8.3834 | 7.9955 | **7.0178** | 8.2217 |
| 3 | 8.3857 | 8.0031 | 7.0122 | 8.2222 |
| 4 | 8.3915 | 8.0092 | 7.0128 | 8.2241 |

⇒ **M 可由 3 降到 2**（重排本体 192 ms → 128 ms，约省 10% 步时），质量几乎不变。

### 3.6 一阶 vs 二阶 SST：判据决定结论 [实测]

`sst2_stft` 提供真正的二阶（含 chirp 率修正 `q̂·τ̂`）IF，与一阶出自同一张 STFT。

- **按“带内集中度（Rényi↓）”判**：二阶在**四个节点上全输**。
- **按“带宽保真度”（增强谱展开度 ÷ 原始谱展开度，→1 = 未改变带宽）判**：二阶在**四个节点上都更保真**，
  且 margin 最大的正是理论预测的漂移带。

| 节点 | 类型 | raw std | 一阶/raw | 二阶/raw |
|---|---|---|---|---|
| LOW_FREQ | 软 | 4.345 | 0.746 | **0.797** |
| BPF_DRIFT | 软 | 1.890 | **0.640** | **0.924** |
| BPF_LINE | 硬 | 1.212 | 0.740 | 0.873 |
| 2xBPF | 硬 | 3.755 | 0.453 | 0.903 |

**这个矛盾本身就是当前的核心问题**：两个判据给出相反结论，而“谁对”取决于
**目标带宽是什么**。见 §4.1。

## 4. 当前待决问题（需要外部意见）

### 4.1 `bw_target` 的定义（核心）

软带需要“保留本征物理带宽”，但**“目标带宽”怎么定义没有解决**：

- 若取**原始 STFT 的带内谱展开度** → **不行**。原始谱含**窗函数泄漏裙边**，
  而挤压的全部意义就是把泄漏收掉。以它为目标是让模型“不要挤压”，方向错了。
  （这解释了 §3.6 为什么两判据矛盾：二阶保住了更多原始带宽，但原始带宽里含泄漏。）
- 若取 `node_bw`（提取器已有的“带内 IF 估计 std”）→ 把“分量在动”和“分量很宽”混在一起。

**一个候选方案（待验证）**：用**原始 STFT 能量 `E_raw = w_n(f)·|STFT(f,t)|²` 加权**，
计算**第 0 层（初阶、未经查表折叠）瞬时频率** `ω₀ = omegas[:, 0]` 的带内加权标准差：

```
μ_ω(n,t)      = Σ_f E_raw(f,t)·ω₀(f,t) / Σ_f E_raw(f,t)
bw_target(n,t) = sqrt( Σ_f E_raw(f,t)·(ω₀(f,t) − μ_ω(n,t))² / Σ_f E_raw(f,t) )
```

**为什么理论上不含窗泄漏** [论证]：对理想单频信号，`V(f,t) = e^{i2πf₀t}·ĝ(f−f₀)`，
对 t 求相位导数得 `2πf₀`，**与 f 无关** —— 主瓣内每个 bin 的一阶相位差分都指向同一个 f₀。
所以窗泄漏只改**幅值**、不改**相位导数**，纯音的 `bw_target ≡ 0`。
对多模态/窄带随机过程，不同 bin 的局部振荡频率确实不同，加权 std 就度量了**剔除单频泄漏后的真实弥散**。

**为什么必须用 `ω₀` 而不是 `omegas[-1]`** [论证]：4 次不动点迭代会把原本分散的邻近频率
**坍缩**到局部极值点上，使软带也被过度浓缩；只有初阶保留未折叠的本征弥散。

**已识别但尚未验证的两个风险**：
1. **量化**：`omegas` 是 **1-indexed 整数 bin** 编码（步长 0.5 Hz）。落在 bin 边界的纯音会随噪声
   在相邻整数间跳，产生 ~0.25–0.5 Hz 的**量化假展宽**，伪装成“本征弥散”。
2. **噪声**：相位差分在低能量 bin 上很噪，`E_raw` 加权能压低但压不掉。
   实测值 = 真弥散 + 噪声底。**锁定带（BPF_LINE/2xBPF）是天然的“纯音对照组”**，
   它的 `bw_target` 应当接近该底。

### 4.2 若 σ 由 `bw_target` 决定，GAT 控制什么？（架构后果）

有人提出：一旦正确区分“窗泄漏（所有频带都该清除）”与“本征物理带宽（软带该保留、硬带为零）”，
则**所有频带的最优重排参与度统一为 100%**，唯一需要随节点自适应变化的变量就只有核宽
`σ_i(t) ≈ max(σ_min, bw_target_i(t))`。

**这个方案有一个严重的架构后果必须澄清**：若 σ 由**测量**决定，而轮数统一，那么
`w_i`（GAT 的输出）**再也没有任何通往输出的路径** —— 整个 GAT / 图 / 物理节点机制会失效。
SAST 的前提正是“GAT 控制挤压策略”。所以必须明确二选一：

- **(A)** σ 仍由 GAT 学习，`bw_target` 只作为**损失目标**（即加一项 `L_bw`）；
- **(B)** σ 由物理量决定，GAT 被移除或改作他用 —— 那是另一个模型。

### 4.3 验证指标已饱和

20 epoch 全量训练后 **Val acc = 1.000（1160/1160）**，且 `L_supcon` 塌到 0.000。
即 **KNN 验证精度已无区分配置的能力**，不能再用作选型依据。所有关于 σ/ridge/轮数的结论
都建立在自建的时频质量指标上（逐节点带内 Rényi + 集中度 + 带内频率标准差）。

这也独立印证了 §2.3 的旁路问题：编码器很可能靠带外底噪把对比损失刷到 0，
使梯度不流向 GAT。

## 5. 待决问题清单

1. `bw_target` 的上述定义（`E_raw` 加权的 `ω₀` 带内 std）是否成立？需要验证量化底与噪声底；
   锁定带是否真能作为“纯音对照”给出接近 0 的值。
2. §3.6 的两个判据（集中度 vs 带宽保真度）矛盾，孰对？这直接依赖问题 1。
3. §4.2 的 (A) 还是 (B)：σ 学习（`bw_target` 作损失目标）还是测量（GAT 失效）？
4. `FreqEncoder` 旁路（92% 带外 bin，带外 1-NN 0.800）是否是 `L_supcon` 塌到 0 与
   “门控不承重”的原因？若屏蔽带外后门控变得承重，则 §3.2 的结论需改述为
   “在当前旁路存在的前提下成立”。
5. 既然 §3.5 显示 R≥2 饱和、§3.3 显示 (σ,R) 单调冗余，是否应把 M 固定为 2 并
   把全部自适应能力交给 σ？
