# SAST：结构感知同步压缩变换

## 讲解文档

> 2026-07-27 | 面向水泵水轮机振动信号的时频分析与故障诊断

---

## 1. 背景与问题

### 1.1 我们要处理什么信号

水泵水轮机振动加速度信号，采样率 1000 Hz，单段 2 秒（2000 点）。信号包含三类频率分量：

| 分量 | 频率范围 | 物理来源 | 信号特征 |
|------|:---:|------|------|
| LOW_FREQ | 8-20 Hz | 尾水管涡带压力脉动 | 宽带非稳态，频率随时间漂移 |
| BPF | 42-55 Hz | 叶片通过频率（Z=9 叶片×转频） | 受水头和负荷调制，FM 带宽约 15 Hz |
| 2xBPF | 90-105 Hz | 动静干涉频率（RSI = 2×BPF） | 纯谐波，频率极度稳定（CV<1%） |

数据集包含 5 种运行工况：空转、低负荷、中负荷、高负荷、抽水。共 9669 个样本。

### 1.2 现有方法的局限

同步压缩变换（SST）是标准的时频分析方法。其 IF 估计基于局部多项式相位近似：N=1 假设信号是纯简谐波，N=2 假设是线性调频，更高阶 N 假设更高阶多项式相位。

Colominas & Meignen（2025）的核心发现：**对同一信号的不同时频位置，不存在单一最优阶数**。靠近瞬时频率的 bin 高阶有益；远离 IF 的 bin 高阶放大噪声。最优阶数是时频平面上每个点的函数。

固定阶 SST 对所有 bin 使用相同阶数，无法区分上述三类分量。Colominas 提出的自适应阶 SST 使用坐标下降为每个 bin 独立选择最优阶数——但这是 NP-hard 组合优化问题，无法用梯度下降，且每个信号需要从头运行完整优化（几秒到几十秒），不能泛化到新信号，不能注入物理先验。

### 1.3 为什么选 STFT 而非 CWT 作为基座

STFT 的频率轴是线性的。BPF 和 2xBPF 之间恒定的 2:1 频率比在 Hz 域是等距的（~50 Hz → ~100 Hz），天然适合构建物理图来表达倍频关系。CWT 的对数频率轴不具备这个性质。

两者的挤压操作是相同的（δ 函数硬重排，把每个系数完整分配到 IF 指向的 bin），区别仅在分析窗。SAST 的创新在挤压阶段：用可变宽度的高斯核替代 δ 函数。

## 2. 方法

### 2.1 核心思路

将逐 bin 阶数选择的组合优化问题转化为神经网络可以处理的连续回归问题。

**不是为每个 bin 直接选择阶数 N ∈ {0,1,...,5}（不可微），而是让 GAT 学习一个连续的信任函数 w_i ∈ (0,1)。** w_i 通过确定性公式映射到两种挤压控制参数：

- **σ_i = σ_min + (1-w_i) × Δσ**（核宽，连续，可微，训练时使用）
- **λ_i = round(w_i × N_max)**（挤压迭代轮数，离散，推理时使用）

训练时梯度通过 σ_i → w_i → GAT 回传；推理时 λ_i 自然继承 w_i 的排序。

### 2.2 为什么选挤压迭代次数而非 IF 阶数

传统 SST 中，高阶意味着用 Taylor 展开的高阶导数估计 IF——高阶导数在噪声区域发散，所以噪声 bin 需要降阶。

MSST 使用不同的 IF 精化机制：`omega_{k+1} = omega_k(omega_k)`——沿频率轴向能量集中的方向迭代查找，而非计算高阶导数。这个操作对所有 bin 都是安全的：谐波 bin 快速收敛，噪声 bin 也是向能量集中方向走，不会发散。

因此 SAST 让所有 bin 统一使用 5 次查找后的最优 IF（omega_5），GAT 控制的是挤压这个动作本身：挤多宽（σ）和挤几轮（λ）。

### 2.3 物理图：GAT 的判断依据

GAT 在一个人工定义的异构图上进行消息传递。图包含 4 个节点和 10 条有向边：

**节点**：
- OP：虚拟节点，携带工况上下文（来自 5 个静态原型的余弦相似度软匹配）
- LOW_FREQ、BPF、2xBPF：三个物理频率节点

**边类型**：
- CONDITION（×3，w=0.6）：OP → 各物理节点，广播工况信息
- HARMONIC（×1，w=0.8）：BPF → 2xBPF，r_nom=2.0，检查倍频比值是否成立
- DRIFT（×2，w=0.15）：LOW_FREQ ↔ BPF，检查能量耦合关系
- ENERGY_COMPETITION（×4，w=0.20-0.25）：物理节点 ↔ 2xBPF，编码"此消彼长"的能量竞争关系

**边特征**（运行时从信号的 IF、能量、带宽实时计算，不嵌入任何预设的 Hz 值）：

| 边类型 | 特征维度 |
|------|------|
| HARMONIC | [实测比值 r_obs, 比值稳定性 σ_r, 能量相关性 Corr_E, 边权重 w, 最小持续性 p] |
| DRIFT | [能量相关性 Corr_E, 能量比 E_ratio, 带宽耦合 bw_coupling, w, p] |
| CONDITION | [工况匹配度 cond_sim, 0, 0, w, 0] |
| ENERGY_COMPETITION | [-Corr_E（负相关程度）, 阵营能量比, 比值稳定性, w, p] |

**GAT 如何从图特征推断可信度**（五条独立证据链）：

1. **比值稳定性 σ_r**（时间维度）：噪声比值逐帧随机波动，连续多帧稳定需要极低概率
2. **能量相关性 Corr_E**（激励源维度）：共享激励源的分量能量同步涨落；独立噪声源不相关
3. **频谱形态 bw_score**（自环）：噪声宽度、峰度不匹配物理预期（如 2xBPF 预期窄带 ~2 Hz）
4. **工况一致性 C_prior**（跨分量维度）：空转工况下 2xBPF 不应很强——先验阻止不合理高信任
5. **多边交叉验证**（图拓扑维度）：每个物理节点至少 3 条入边，多角度独立验证

单条证据可能被噪声偶然满足。五条同时满足的联合概率极低。

### 2.4 PPM：原型记忆与门控融合

Physics Prototype Memory 提供物理类型的可学习先验。

- 每个物理节点有频率类型嵌入（HYDRAULIC / BLADE_PASS / BLADE_HARMONIC）
- 节点观测特征与可学习原型做交叉注意力（self-bias=3.0，鼓励关注自身原型）
- 门控融合：h_enhanced = (1-gate) × h_raw + gate × proto_context

当物理边 gate 高（倍频成立、能量耦合存在），模型更多依赖原型知识；当 gate 低（物理关系不成立），自动退回原始观测特征。

### 2.5 阶数如何在 bin 级生效

GAT 输出节点级 w_i，通过两步完成逐 bin 阶数控制：

**节点级**：λ_i = round(w_i × N_max)，决定该分量的基础挤压轮数。

**bin 级**：在节点区域内进一步分化。计算每个 bin 到脊线（能量最大的 bin）的距离和能量比：

```
ridge_factor = (|STFT[η,t]| / max_energy) × exp(-|η - ridge_pos|² / (2 × bw_expected²))
```

脊线 bin → ridge_factor ≈ 1 → 参与全部 λ_i 轮挤压；远离脊线的低能 bin → ridge_factor ≈ 0 → 不参与挤压。实现了同节点内脊线附近和远离脊线 bin 的差异处理。

### 2.6 训练：全自监督，无需标签

损失函数由四项组成，均不依赖人工标注：

| 项 | 名称 | 监督来源 | λ |
|---|------|:---:|:---:|
| RE_2D | Rényi 2D 熵 | TFR 自身集中度 | 0.1 |
| L_physics | 比值偏差 × w_src × w_dst × gate | 叶片数 Z=9（机械设计参数） | 0.5 |
| L_smooth | w_i 帧间差分 | 正则化 | 0.05 |
| L_balance | w_mean 区间约束 [0.3, 0.8] | 正则化 | 0.01 |

不需要分类交叉熵。RE_2D 提供"TFR 应集中"的全局信号，L_physics 按边类型修正——"倍频关系成立时集中是对的，不成立时集中是错的"。两者博弈使 GAT 对 2xBPF（倍频成立）给高 w_i，对 LOW_FREQ（无倍频约束）给低 w_i。

## 3. 实现

### 3.1 CUDA MSST 全流程加速

原始 MSST 的 STFT 步骤使用 Python for 循环 + numpy FFT，是主要瓶颈（T=2000 时约 4 秒）。

实现的 CUDA 加速方案：
- **STFT**：CUDA kernel 填充时频缓冲区（每时间列一个 block），cuFFT 批量 FFT。精确复刻 numpy 的 modulated-form STFT（循环索引 + 边界截断窗），数值误差 < 3×10⁻¹⁴
- **IF 估计**：纯 torch 操作（angle, unwrap via cumsum, diff），GPU 上运行
- **挤压**：torch scatter_add（等效于 numpy 的双重 for 循环硬挤压）

### 3.2 性能

T=2000 真实信号长度，GTX 1650 GPU：

| 步骤 | Numpy (ms) | CUDA (ms) | 加速比 |
|------|:---:|:---:|:---:|
| STFT | 158 | 14 | 11× |
| IF 估计 | — | 6 | — |
| 挤压 | 4406 | 15 | 288× |
| **总计** | **4097** | **36** | **115×** |

TFR 与 numpy MSST 的相关性 0.999999。Rényi 熵差异 < 0.01。

5 个真实样本（9669 样本数据集）平均每样本 42 ms。

## 4. 能力边界

### 4.1 TFR 质量改善

| 分量 | MSST 表现 | SAST 改善 |
|------|------|------|
| 2xBPF | 已近乎完美 | 几乎没有——N=1 已收敛，不需要自适应 |
| BPF | 硬挤抹掉 ~15 Hz 调制带宽 | 保留工况调制结构——TFR 不虚构"稳定谐波" |
| LOW_FREQ | 强行挤压宽带信号，制造伪结构 | 不挤压——保留水力带宽原貌 |

### 4.2 对分类精度的直接贡献

预计很小（1-2% 以内）。原因是：分类器（GlobalAvgPool → MLP）依赖的是频段之间的能量比（如 R_LF vs R_BPF vs R_2xBPF），这个信息在 GlobalAvgPool 沿频率轴压缩后，不受频段内部能量分布变化的影响。SAST 改变的是频段内部能量分布（TFR 的"形状"），不是频段间的总量分配。

### 4.3 SAST 的核心价值

1. **可解释性**：输出 w_i(t)（分量信任度）、gate_edge(t)（物理关系满足度）、alpha(t)（工况匹配模式）、sigma_sq（逐 bin 核宽）。这些输出对故障诊断工程师的价值超过 TFR 本身。

2. **跨工况泛化**：GAT 学的是物理关系的自洽性（比值稳定性、能量相关性），不是具体的频率值。换到新工况或新机组（叶片数不同），改图模板即可，不需重新训练。

3. **异常检测能力**：gate_edge 下降 → 物理关系破坏（如倍频比值漂移 → 滑差/失速）；所有原型 alpha 都低 → 工况不在训练包络内。

4. **OOD 检测**：静态原型软匹配可识别"与任何已知工况都不像"的信号。

## 5. 实验验证

### 5.1 不同阶数 SST 的效果差异

在合成信号和真实信号上运行 N=1~5 阶 MSST，验证不同分量对不同阶数的响应：

- **2xBPF**：Rényi 从 11.08（N=1）降到 11.02（N=5），改善极小（Δ=0.06）。N=1 已足够。
- **BPF**：Rényi 从 11.72（N=1）降到 11.00（N=5），改善显著（Δ=0.72）。FM 调制需要高阶 chirp 修正。
- **LOW_FREQ**：Rényi 从 11.07（N=1）降到 10.99（N=5），但这是破坏性的——宽带涡带信号被强行挤成假细线。

Rényi 熵在所有分量上都随阶数升高而下降。纯数据驱动会把所有 bin 推向最高阶。这正是需要物理图来约束 LOW_FREQ 的原因。

### 5.2 CUDA MSST 时频图质量

在真实 Class 2（中负荷）样本上，CUDA MSST 与 numpy MSST 的 TFR 相关性 0.999999，最大差异 0.005（浮点舍入误差），48 Hz 脊线形态完全一致。
