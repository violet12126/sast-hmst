# SAST：结构感知同步压缩变换

## 讲解文档

> 2026-07-27 | 面向水泵水轮机振动信号的时频分析与故障诊断
> **v4 更新 (2026-07-31)**: 损失函数与可微性重大重构，详见 [v4 更新说明](#v4-更新2026-07) 及 `SAST_v4_design.md`

## 1. 背景与问题

### 1.1 我们要处理的信号

水泵水轮机振动加速度信号，采样率 1000 Hz，单段 2 秒（2000 点）。信号包含三类频率分量：

| 分量 | 频率范围 | 物理来源 | 挤压策略 |
|------|:---:|------|------|
| LOW_FREQ | 2-25 Hz | 尾水管涡带压力脉动 | **宽核, 不挤** — 涡带本征宽带, 不存在锐利 IF, 硬挤会产生虚假细线 |
| BPF | 42-55 Hz | 叶片通过频率（Z=9 叶片×转频） | **中核, 多轮** — FM 调制需要多轮挤压逐次追 chirp |
| 2xBPF | 90-105 Hz | 动静干涉频率（RSI = 2×BPF） | **窄核, 单轮** — 纯谐波, 一轮到位 |

数据集包含 5 种运行工况：空转、低负荷、中负荷、高负荷、抽水。共 9669 个样本。

### 1.2 现有方法

同步压缩变换（SST）包含两步：(1) IF 估计——判断能量往哪里挤；(2) 挤压——把能量挪过去。传统 SST 的控制点在于步骤 (1)：不同 bin 用不同阶数的 IF 估计。

固定策略 SST（包括 MSST）对全频段使用相同处理。

### 2.2 静态原型软匹配：工况上下文注入

**离线阶段**：对 5 类 9669 个样本逐类计算 FFT，提取三个频段的能量占比，形成 5 个 4 维原型向量：

```
V_proto = [R_LF, R_BPF, R_2xBPF, log10(E_BPF/E_2xBPF)]

原型 0 (空转):   [0.038, 0.209, 0.027, +0.99]   ← 低频主导, RSI 弱
原型 1 (低负荷): [0.068, 0.833, 0.010, +1.99]   ← BPF 主导
原型 2 (中负荷): [0.046, 0.270, 0.304, +0.00]   ← BPF/RSI 过渡
原型 3 (高负荷): [0.013, 0.153, 0.652, -0.65]   ← RSI 绝对主导
原型 4 (抽水):   [0.021, 0.686, 0.099, +0.85]   ← BPF+RSI 双强
```

**在线推理**：每帧从信号实时计算同样的 4 维向量 V_obs(t)，与 5 个原型做余弦相似度，经 softmax 得到注意力权重 α(t) ∈ [0,1]^5：

```
sim(t, k) = cosine(V_obs(t), prototype_k)   k=0..4
α(t) = softmax(sim / τ)                     温度 τ=0.1 控制软硬程度

cond_ctx(t) = Σ α_k(t) × P_embed[k]        可学习的原型解释嵌入
```

**关键设计**：不预测工况类别。α(t) 是软注意力权重，不是类别概率。cond_ctx(t) 是 5 个原型的加权混合，携带"当前信号能量分布最像哪种典型工况"的信息。P_embed 是可学习的——模型学到了"像原型 k 时应该如何调整挤压策略"。

### 2.3 物理图：GAT 的判断依据

图包含 4 个节点和 10 条有向边。每个节点和每条边都有明确的物理含义。

**节点定义**：

```
┌─────────────────────┐
│   工况上下文节点        │  携带 cond_ctx（来自原型匹配的工况嵌入向量）
│   (Operating Context)  │  不直接对应任何频率分量
│   虚拟节点, 不输出 w    │  作用：向三个物理节点广播工况信息
└──────┬──┬──┬─────────┘
       │  │  │  CONDITION (w=0.6)
       ▼  ▼  ▼
┌──────────┐ ┌──────────┐ ┌──────────┐
│ LOW_FREQ │ │   BPF    │ │  2xBPF   │
│ 2-25 Hz  │ │ 42-55 Hz │ │ 90-105 Hz│
│ 水力涡带  │ │ 叶片通过  │ │ 动静干涉  │
│ 宽带非稳态│ │ FM 调制  │ │ 纯谐波    │
└────┬─────┘ └──┬───┬───┘ └────┬─────┘
     │          │   │           ▲
     │  DRIFT   │   └───────────┘
     │ (w=0.15) │   HARMONIC (r=2.0, w=0.8)
     │          │   "2xBPF 是 BPF 的 2 倍频"
     │          ▼
     └─────────►┘
    "低频增强 → BPF 调制"

    ENERGY_COMPETITION (此消彼长):
      LOW_FREQ ←──→ 2xBPF  (w=0.25)  "低频强时 RSI 弱, RSI 强时涡带弱"
      BPF      ←──→ 2xBPF  (w=0.20)  "BPF 强时 RSI 弱, RSI 强时 BPF 弱"
```

**四个节点的职责**：

| 节点 | 类型 | 输入特征 | GAT 需要判断的问题 |
|------|------|------|------|
| 工况上下文节点 | 虚拟 | cond_ctx (来自原型匹配) | —（仅向物理节点广播工况信息, 不输出 w） |
| LOW_FREQ | 物理 | IF(t), energy(t), bw(t), persistence | "低频水力信号——此刻应该挤吗？" |
| BPF | 物理 | IF(t), energy(t), bw(t), persistence | "FM 调制分量——倍频关系成立吗？该挤几轮？" |
| 2xBPF | 物理 | IF(t), energy(t), bw(t), persistence | "纯谐波——倍频验证通过就可以挤" |

**四条边类型的作用**：

| 边类型 | 数量 | 编码的物理知识 | 怎样影响 GAT 的信任判断 |
|------|:---:|------|------|
| CONDITION | 3 | 工况决定各分量强弱 | 空转→LOW_FREQ 应受关注；高负荷→2xBPF 应受关注 |
| HARMONIC | 1 | BPF 和 2xBPF 的频率比应为 2.0 | 比值 r_obs≈2.0→gate 高→IF 可信；比值漂移→gate 低→不可信 |
| DRIFT | 2 | 低频能量与 BPF 调制正相关 | 能量相关 Corr_E 高→耦合存在→可信度中；相关消失→降信 |
| ENERGY_COMPETITION | 4 | LOW_FREQ/BPF 与 2xBPF 随负荷反向变化 | 负相关显著→竞争关系成立→区分对待两阵营；不相关→不确定 |

**边特征**（运行时从信号实时计算）：

| 边类型 | 特征维度 (dim 0-4) |
|------|------|
| HARMONIC | [实测比值, 比值稳定性(窗口 std), 能量相关性, 权重, 持续性] |
| DRIFT | [能量相关性, 能量比对数值, 带宽耦合度, 权重, 持续性] |
| CONDITION | [cond_ctx 与节点特征的余弦相似度, 0, 0, 权重, 0] |
| ENERGY_COMPETITION | [负相关程度, 阵营能量比, 比值稳定性, 权重, 持续性] |

### 2.4 PPM + GAT：从图到信任度

**PPM (Physics Prototype Memory)**：提供物理类型的可学习先验，增强节点特征。

- 每个物理节点有频率类型嵌入（HYDRAULIC / BLADE_PASS / BLADE_HARMONIC），编码"这个节点是什么类型的物理分量"
- 节点观测特征与可学习原型做交叉注意力，self-bias=3.0 鼓励节点关注自身类型的原型
- 门控融合：`h_enhanced = (1-gate) × h_raw + gate × proto_context`。gate 高（物理关系成立）→信任原型知识；gate 低（关系不成立）→回退到原始观测

**EdgeConditionedGAT**：2 层 × 4 头边条件图注意力。每层对每条边计算注意力权重 α_ij，聚合源节点的消息到目标节点：

```
α_ij = softmax(LeakyReLU(a^T [W_q·h_dst || W_k·h_src || W_e·e_ij]))
h_i_new = LayerNorm(h_i + ReLU(Σ_j α_ij · V·h_j))
```

GAT 输出：`w_i = sigmoid(MLP(h_i)) ∈ (0,1)`，每物理节点每帧一个值。

**GAT 学到的行为**（无需手动编码规则，通过损失函数驱动）：
- HARMONIC 边 r_obs≈2.0 + σ_r 小 → 高注意力 → w_2xBPF↑ → σ↓ → 窄核挤压
- DRIFT 边 Corr_E 高 → 中注意力 → 耦合正常
- COMPETITION 边 -Corr_E 大 → 竞争关系确认 → w_LOW 和 w_2x 反相关
- 所有边信号弱 → w_i↓ → σ↑ → 宽核/不挤压

### 2.5 挤压轮数 + 核宽如何在 bin 级生效

GAT 输出节点级 w_i，同时决定核宽 σ_i 和挤压轮数 λ_i：

**σ_i（核宽）**：控制挤压时能量沿频率轴的散布范围。

```
σ_i = σ_min + (1 - w_i) × Δσ

w_i → 1 (2xBPF):    σ → σ_min (0.5 bin)  ← 窄核, 能量高度集中
w_i → 0.7 (BPF):    σ → 中 (4 bin)       ← 适度保留调制结构
w_i → 0 (LOW_FREQ): σ → σ_max (15 bin)   ← 宽核, 几乎不改变原始能量分布
```

低频需要宽核的物理原因：涡带信号的本征带宽约 10-15 Hz——这是真实的水力脉动频率范围，不是测量模糊。用窄核挤压会把分布在 2-25 Hz 的涡带能量强行集中到某个单一频率，制造出不存在的"锐利低频分量"。宽核使挤压核宽度大于信号的本征带宽，能量几乎原样保留。

**λ_i（挤压轮数）**：控制挤压-重估 IF-再挤压的循环次数。

```
λ_i = round(w_i × N_max)

w_i → 1 (2xBPF):    λ = 1  ← 一轮到位（IF 已收敛）
w_i → 0.7 (BPF):    λ = 3~5 ← 多轮追 chirp（每轮 SNR 提升, IF 更准）
w_i → 0 (LOW_FREQ): λ = 0   ← 不挤压
```

**bin 级分化**：同一节点内，脊线附近 bin 和远离 bin 进一步区分。计算每个 bin 到脊线（能量最大的 bin）的距离和能量比：

```
ridge_factor = (|STFT[η,t]| / max_energy) × exp(-|η - ridge_pos|² / (2 × bw_expected²))
```

脊线 bin → ridge_factor ≈ 1 → 参与全部 λ_i 轮, 使用节点级 σ_i；远离脊线的低能 bin → ridge_factor ≈ 0 → 跳过挤压。σ_i 和 λ_i 的组合覆盖了三种场景：窄核+单轮（2xBPF）、中核+多轮（BPF）、宽核+零轮（LOW_FREQ）。

### 2.5 训练：全自监督，无需标签

损失函数由四项组成，均不依赖人工标注：

| 项 | 名称 | 监督来源 | λ |
|---|------|:---:|:---:|
| RE_2D | Rényi 2D 熵 | TFR 自身集中度 | 0.1 |
| L_physics | 比值偏差 × w_src × w_dst × gate | 叶片数 Z=9（机械设计参数） | 0.5 |
| L_smooth | w_i 帧间差分 | 正则化 | 0.05 |
| L_balance | w_mean 区间约束 [0.3, 0.8] | 正则化 | 0.01 |

不需要分类交叉熵。RE_2D 提供"TFR 应集中"的全局信号，L_physics 按边类型修正——"倍频关系成立时集中是对的，不成立时集中是错的"。两者博弈使 GAT 对 2xBPF（倍频成立）给高 w_i，对 LOW_FREQ（无倍频约束）给低 w_i。

> **v4 更新 (2026-07)**: 以上为 v3 原始设计。v4 做了以下重大重构，详见 `SAST_v4_design.md`：
> - **可微性修复**：`SparseGaussianReassigner` 的 `argmin` 量化改为连续高斯核（`w=exp(-0.5*(k/sigma)^2)/Z`），修复 `tfr_enhanced` 对 `sigma_sq` 不可微的梯度断裂问题。修复后 TFR loss 能回流到 w_i（grad ~9.7e-4，修复前为 0）。
> - **L_task → SupCon**：分类 CE 替换为监督对比损失（Khosla 2020），同工况 TFR 表示 z_freq 拉近、不同工况推远。用工况标签定义正负对但**不分类**。评估改为 KNN（z_freq 到类中心最近邻）。`TFRClassifier` → `FreqEncoder`（LayerNorm 替代 BatchNorm）。
> - **RE_2D per-region 选择性**：全局 Rényi 熵改为 per-region 选择性——HARMONIC/BLADE_PASS 频段最小化熵，HYDRAULIC（LOW_FREQ）不惩罚，修复全局熵"鼓励所有能量集中"与选择性挤压的冲突。
> - **L_physics 约束 A_ij**：约束对象从 w_i 改为 A_ij（GAT 注意力），按边类型差异化 ℓ（HARMONIC=`|r_obs-r_nom|/r_nom`、CONDITION=`1-cond_sim`、DRIFT=`1-Corr_E`、COMPETITION=`1-(-Corr_E)`）。修复 v3 的 gate_edge×ratio_dev 互消致 ~0 问题。
> - **总损失**：`L = λ_sc·L_supcon + λ_e·RE_2D + λ_p·L_physics + λ_s·L_smooth + λ_b·L_balance`。SupCon 主监督，其余辅。
> - **工况匹配固定不学习**：`StaticPrototypeMatcher` 的 alpha 从 cosine 直接计算，无可学习参数。职责分离——原型负责工况识别（固定），GAT 负责挤压策略（学习）。
> - **去掉合成预训练**：方案A（信号重建）和方案B（理想 w_i 直接监督）均已删除，被 SupCon 自监督替代。

## 3. 实现

### 3.1 CUDA MSST 全流程加速

原始 MSST 的 STFT 步骤使用 Python for 循环 + numpy FFT，是主要瓶颈（T=2000 时约 4 秒）。

实现的 CUDA 加速方案：
- **STFT**：CUDA kernel 填充时频缓冲区（每时间列一个 block），cuFFT 批量 FFT。精确复刻 numpy 的 modulated-form STFT（循环索引 + 边界截断窗），数值误差 < 3×10⁻¹⁴
- **IF 估计**：纯 torch 操作（angle, unwrap via cumsum, diff），GPU 上运行
- **挤压**：torch scatter_add（等效于 numpy 的双重 for 循环硬挤压）

### 3.2 性能

T=2000 真实信号长度，GTX 1650 GPU：

| 步骤 | Numpy (ms) | CUDA (ms) | 加速比 |
|------|:---:|:---:|:---:|
| STFT | 158 | 14 | 11× |
| IF 估计 | — | 6 | — |
| 挤压 | 4406 | 15 | 288× |
| **总计** | **4097** | **36** | **115×** |

TFR 与 numpy MSST 的相关性 0.999999。Rényi 熵差异 < 0.01。

5 个真实样本（9669 样本数据集）平均每样本 42 ms。

### 4.2 对分类精度的直接贡献

预计很小（1-2% 以内）。原因是：分类器（GlobalAvgPool → MLP）依赖的是频段之间的能量比（如 R_LF vs R_BPF vs R_2xBPF），这个信息在 GlobalAvgPool 沿频率轴压缩后，不受频段内部能量分布变化的影响。SAST 改变的是频段内部能量分布（TFR 的"形状"），不是频段间的总量分配。

### 4.3 SAST 的核心价值

1. **可解释性**：输出 w_i(t)（分量信任度）、gate_edge(t)（物理关系满足度）、alpha(t)（工况匹配模式）、sigma_sq（逐 bin 核宽）。这些输出对故障诊断工程师的价值超过 TFR 本身。

2. **跨工况泛化**：GAT 学的是物理关系的自洽性（比值稳定性、能量相关性），不是具体的频率值。换到新工况或新机组（叶片数不同），改图模板即可，不需重新训练。

3. **异常检测能力**：gate_edge 下降 → 物理关系破坏（如倍频比值漂移 → 滑差/失速）；所有原型 alpha 都低 → 工况不在训练包络内。

4. **OOD 检测**：静态原型软匹配可识别"与任何已知工况都不像"的信号。
